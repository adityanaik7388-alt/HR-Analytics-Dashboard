# 📊 HR Analytics Dashboard | Power BI

**Turning HR Data into Meaningful Insights!**

## 🚀 About the Project
An interactive HR Analytics Dashboard developed using Power BI to analyze employee attrition, understand workforce trends, and support data-driven HR decisions.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

## 📌 Key Performance Indicators
- Total Employees
- Active Employees
- Attrition Count
- Attrition Rate
- Average Age
- Average Experience

## 📈 Key Analysis
- Employee Attrition by Department
- Attrition by Job Role and Salary
- Age and Gender Analysis
- Job Satisfaction Analysis
- Top 5 Job Roles by Attrition

## 💡 Project Highlights
- Interactive dashboard with dynamic slicers.
- Data cleaning and transformation using Power Query.
- KPI development using DAX measures.
- Visual insights to support employee retention analysis.

Data Analytics | Data Cleaning | Data Modeling | DAX | Power BI | Data Visualization
